### 调用大模型API

**本节目标**：完成Python程序调用Qwen模型，实现通过代码向大模型发送请求并获取返回结果。

本教程以阿里云百炼平台提供的 Qwen（通义千问）大模型 API 为例，介绍大模型 API 的基本调用流程。其他国产或开源大模型 API 的调用方式与此类似。

1. 注册及获取Qwen API Key

   - 注册并登录阿里云百炼平台（注意：登陆**中国版**而非国际版，区分方式见左上角平台名为中文或英文）：https://bailian.console.aliyun.com/cn-beijing?utm_content=se_1021228063&gclid=EAIaIQobChMIoZyyp5qulgMVY4xoCR2Spz3KEAAYAiAAEgL7y_D_BwE#/home

   - 点击顶部 **API参考**，点击下文**中国大陆版**

   - 点击右上角**创建API Key**，直接点确认即可

   - 弹出保存你的API Key界面，**立刻保存API Key**（注意API Key不能随意泄露，如投喂给AI）

   - 打开VSCode**安装依赖库**，在顶部菜单栏点击**终端**，输入

     ```python
     pip install openai python-dotenv
     ```

   - 在VSCode的项目文件中创建命名为**.env**文件，填写

     ```python
     DASHSCOPE_API_KEY=你的API_KEY
     ```

     （此处自己手动输入刚刚保存的API Key）

   - 在VSCode的项目文件中创建命名为main.py文件，输入

   ```python
   from openai import OpenAI
   from dotenv import load_dotenv
   import os
   
   
   # 加载环境变量
   load_dotenv()
   
   
   # 初始化客户端
   client = OpenAI(
       api_key=os.getenv("DASHSCOPE_API_KEY"),
       base_url="https://dashscope.aliyuncs.com/compatible-mode/v1"
   )
   
   
   # 调用模型
   response = client.chat.completions.create(
       model="qwen-plus",
       messages=[
           {
               "role": "user",
               "content": "请介绍一下机器学习中的随机森林算法"
           }
       ]
   )
   
   
   # 输出结果
   print(response.choices[0].message.content)
   ```

   - 在**VSCode终端**运行

     ```
     python main.py
     ```

   - 如果成功，会返回 

     > 随机森林(Random Forest)是一种集成学习算法...



### 利用大模型辅助编程

**本节目标**：学习如何通过合理编写 Prompt，提高大模型辅助编程的效率。

- 指定AI**身份**，例如：“你是一个资深数据分析师/程序员”

- 讲清任务**目的、方法**，明确**输入、输出**格式以及**代码语言**

- 如果不确定自己的代码具体要求，可以让AI提出需要确认的问题

### 如何写出高效修改报错代码的prompt

**本节目标**：学习如何向 AI 提供有效的报错信息，并引导 AI 分析错误原因、提出修改方案。通过规范描述问题，提高代码调试过程中的沟通效率。

1. 告诉AI自己的**目的**，提出出现错误的**具体代码步骤**和**报错情况**
2. 让它完成：**分析报错原因**，**修改方式**
3. 若修改后仍然报错，补充**最新代码、新的报错信息、已尝试的修改方式**
